# Changelog

## 0.2.0

First VS Code extension release.

- Native WoW macro language support: highlighting, contextual IntelliSense, inline Lua, hover help, Outline, Problems, quick fixes, and character/byte budgets.
- Local library with autosave, search, class filters, favorites, metadata, Markdown notes, recoverable Trash, and conflict protection across windows.
- The latest 100 content revisions per macro, native revision comparisons, and restoration.
- 36 guided samples plus native snippets, including stance dancing, shapeshifting, and form-sensitive actions.
- Spellbook desktop and Forever Atlas JSON import/export compatibility, plain macro files, and custom spell/item autocomplete catalogues.
- Installable universal VSIX; no external runtime service or game connection.
